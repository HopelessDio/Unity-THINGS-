# Unity-THINGS-

## Free 2D art resources

This is a top-down survival arena game with waves of mutant enemies and melee/rage combat. These sites have free sprites, animations, and tilesets to explore:

- [Kenney Assets](https://kenney.nl/assets) — free game art packs. Check each pack page for its license.
- [itch.io: free top-down 2D game assets](https://itch.io/game-assets/free/tag-2d/tag-top-down) — community-made characters, sprite sheets, animations, and tilesets. Licenses vary by creator.
- [OpenGameArt: top-down assets](https://opengameart.org/content/top-down-assets-1) — a collection of free community art. Check each asset's license and attribution requirements.

Useful searches: `free top-down horror tileset`, `hand-painted monster sprite sheet`, and `top-down enemy attack animation`.

The current enemy art is detailed and hand-painted, so try to find a similar art style to keep the game visually consistent. Before using an asset, check its license and save the creator and license details for the game's credits.
